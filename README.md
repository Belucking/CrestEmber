# CrestEmber

Translates and synchronizes time zone and daylight saving time adjustments across multiple calendar systems.

CrestEmber is built to be simple and practical, focusing on doing one thing well.

**Why CrestEmber?**

- Translates and synchronizes time zone
- and daylight saving time adjustments
- across multiple calendar systems

## Key Features

- Translates and synchronizes time zone
- and daylight saving time adjustments
- across multiple calendar systems

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/CrestEmber.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

CrestEmber is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
